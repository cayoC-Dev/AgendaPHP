# 📅 AgendaPHP

Sistema de agenda desenvolvido em **PHP** para organização e gerenciamento de compromissos.

## 🛠️ Tecnologias

* PHP
* HTML5
* CSS3
* MySQL

## 🚀 Funcionalidades

* 📋 Cadastro de compromissos
* ✏️ Edição de registros
* 🗑️ Exclusão de registros
* 📅 Visualização da agenda

## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/cayoC-Dev/AgendaPHP.git
```

Depois, coloque o projeto no servidor local (como **XAMPP**) e acesse:

```text
http://localhost/AgendaPHP
```
